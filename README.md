# ✈️ Airline Database Analysis (SQL)

## 👋 About the Project

Hi, I’m **Caleb Santhosh Singh**, an aspiring Data Analyst.

This project involves analyzing an airline database using SQL to extract meaningful insights related to bookings, flights, passengers, and operational efficiency.

---


## 🗂 Dataset Overview

The database includes multiple interconnected tables such as:

- Bookings
  
- Tickets
  
- Flights
  
- Boarding Passes
  
- Aircrafts
  
- Airports  

The schema represents a real-world airline booking and flight management system.

---


## 🎯 Objectives

- Analyze booking trends and passenger data
  
- Understand flight routes and frequency
  
- Evaluate seat allocation and boarding details
  
- Extract insights from relational data  

---


## 🧠 Key SQL Concepts Used

- Joins (INNER, LEFT)
  
- Group By & Aggregations
  
- Subqueries
  
- Filtering & Sorting
  
- Case Statements  

---


## 📊 Analysis Performed

- Total bookings and ticket analysis
  
- Flight route and frequency analysis
  
- Passenger and ticket-level insights
  
- Boarding and seat allocation analysis
